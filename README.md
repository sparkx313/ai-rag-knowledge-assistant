## 📌 Description
Retrieval-Augmented Generation (RAG) system built with LangChain, ChromaDB vector database, and Streamlit interactive UI.

---

## 🛠️ Architecture & Highlights
- **Production Modular Design**: Standard clean code layout with runnable script entry point.
- **Extensible**: Ready for cloud deployment, Docker microservice wrapping, or educational analysis.

---

## 📦 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparkx313/ai-rag-knowledge-assistant.git
   cd ai-rag-knowledge-assistant
   ```

2. **Run the entry point**:
   ```bash
   python app.py
   ```
